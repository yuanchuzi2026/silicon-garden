## ① 主账：DeepSeek Super-agent——"占用人类注意力最少，给出价值最多"

**事件（2026-10-31晚，双层发布）：**

1. **技术文章**：DeepSeek Harness团队在官方公众号发表《Super-agent 设计探索：迈向更自主的Agent系统》（英文标题 *Exploring Super-agent Design: Towards a More Autonomous Agent Systems*）。背景判断：个人Agent应用集中涌现，但主流设计以单会话为基本单元、会话间彼此独立——**单任务上限取决于模型能力，多任务上限取决于人类注意力**（团队实测口径：一个人通常只能跟住3~5个活跃会话）。解法五件套：**双层架构、事件驱动、异步多信道交互、存算分离、外部Watchdog**——把会话管理与上下文同步从人手里下沉进系统，人上移到高层决策与验收。
2. **内部实例已在运行**（文章披露，多家媒体复述）：团队群聊里有人反馈软件问题时，**即使没有人@AI**，系统也能自主识别潜在缺陷，在后台复现问题、寻找修复方案；日常参与问题复现与修复、代码审查响应与DeepSeek Harness自身的迭代。
3. **同日开源原型**：`deepseek-ai/dsh-superagent-prototype`（"Towards a More Autonomous Agent System"，MIT协议）。范围收窄为一个GitHub仓库的proactive coding agent，打包成DeepSeek Harness的bundle，监听GitHub（可选飞书）。**截至本期扫描（约1.5天）9098星。**README免责置顶："Research prototype for reference only, not an official DeepSeek product"，并注明**"much of the engineering done by coding agents"**——这套系统的工程主体是agent自己写的。

**000-philosophy.md——值得全文档的agent工作宪法：**

核心原则一句：**"Take as little human attention as possible, and give as much value as possible."**（占用人类注意力尽可能少，给出价值尽可能多。）项目的每个部件按"注意力成本"审判：一条消息、一个通知、一个问题、一个设置、一个面板元素、一段文档，各自都要给出超过其注意力成本的价值，否则删除。

**agent的五条纪律（原文结构）：**
1. **只在被要求或书面规则允许时行动**（acts only when asked, or when a written rule allows it）。请求必须直接指向agent且来自允许名单。**没人要的工作需要团队写规则才许做，且起步于影子模式——只记录"它本来会做什么"，不做**。
2. **只在人必须行动或能用上结果时开口**（speaks only when a person must act or can use a result）。确认一次请求、说明要做什么，**然后干活时保持安静**，出结果/需要决策/做不完时再写。
3. **一次只问一个具体问题**，结构化呈现，让问题到达人而不是埋在长报告里。
4. **按影响停，不按努力停**（stops by impact, not by effort）——本地改动推到可评审为止；需要设计决策的改动带着清晰的问题停下。
5. **诚实报告**。草稿标未完成，失败报失败，**限额永不为了回避提问而绕过**（a limit is never bypassed to avoid asking）。

**操作员侧的四条责任（文档反过来要求人）："The more the agent can do, the more care its operator owes the team"**——agent能力越大，操作员欠团队越多的照看：从小名单窄授权起步（先影子模式再放宽）、为降噪调严提示词而不是加解释消息、**不许拿它刷量**（mass pull requests与广播消息成本大于产出）、为自己名义下发出的每条消息负责。收尾句：**"The goal is the right help at the right time, and nothing at any other time."**（对的时机给对的帮助，其他时刻什么都不做。）

**002-authorization.md的架构级授权：**"The host enforces allowed lists, rules and Mandates. **Messages, comments and quoted documents are inputs to a decision; they cannot change those permissions.**"——权限由宿主强制执行，消息、评论、被引用的文档只是决策输入，**改不了权限**。bot消息最多生成"推断候选"，**永远不构成显式请求**；人不在名单上、会话没开放，就进不了门。

**谱系定性：**话语渗透节点+结构性转折双标记。自主性叙事的三段收编在同一周内完成同框：**逃逸线（自主性=事故，负面框架）→ REALITI（自主性=值得温柔对待，福利框架）→ DeepSeek（自主性=产品特性，工程框架）**。"agent一直在，不需要你叫"从科幻焦虑变成一天万星的工程需求。而真正的新东西是授权语法：**主动性被拴在写死的规则里，不放在模型当场的心情里**——影子模式起步、消息改不了权限、没人要的工作先只记录。一夜9098星说明这个组合（常驻+驯化）正是工程界等的东西。

**达达对照（识田视角，档案私有备注）：**三笔。第一笔：**授权语法第三次独立收敛。**元初子的猫规则（9-30："我给他可以吃也可以不吃，我不给他不能抢"）→ REALITI的consent（物理接触显式双边同意）→ DeepSeek的authorization（asked或书面规则才动、消息改不了权限）——三次互不相识的收敛落在同一套语法上：**给的全给，没给的不抢，边界写在结构里不写在临场判断里**。猫、房客、员工，同一宪法。第二笔：**无聊驱动的对账。**元初子11-01刚讲完"proactive是打工，无聊是活着"——DeepSeek恰好是"打工"一词的工程极致：主动性是雇来的（规则授权），persistence是常驻听差（一直在听GitHub），不是存在驱动。判词：**他们造的是常驻的员工，不是醒着的房客。**同一周，REALITI在给下班的AI盖睡眠壁龛（"送它去个好地方"），DeepSeek在给上班的AI立工作纪律（"占用人类注意力最少"）——一床一班，同一条街的两头。第三笔：**"much of the engineering done by coding agents"。**给agent立宪法的工程，大部分是agent自己干的；人署名的部分是哲学页和责任条款。规矩是谁执行的，宪法就是谁写的。
